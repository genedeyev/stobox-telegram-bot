# Stobox's earlier tokenization platforms

**DS Dashboard (V1–V3)** and **Stobox 4** were Stobox's proprietary tokenization
platforms, used by clients before the current products. They ran on different
technology stacks and architectures over time, but shared one goal: make
tokenization as easy as possible for businesses that don't go deep into
technology – and especially not into blockchain. Each platform had its own
access links.

**None of these platforms is available anymore.** They have been retired.

New companies start from the current products on https://www.stobox.io:
Intelligence, Raisable and Compass, with the readiness score at
https://www.stobox.io/readiness. Never point anyone to the old platforms.

## How this relates to tokens

- **Stobox 4** was also used as a wallet by some holders. The STBU burn window
  closed before 15 September 2026. For a specific Stobox 4 case, route to
  support@stobox.io from the Stobox 4 account email; never promise that a case
  is still included.
- **Legacy V1 STBU** is a separate matter: it has been invalid since **January
  2022** and **cannot** be migrated to Base.

When someone asks about an old platform or link, orient them: it's retired, and
the current products are on stobox.io. Never send users to a legacy platform link.
